# ordermetrics for Mac: downloads

This repository holds the released builds of **ordermetrics**, the profit dashboard for online stores that runs on your Mac, and the feed the app uses to update itself.

- Get the app: [ordermetrics.com](https://ordermetrics.com)
- Requires a Mac with Apple silicon (M1 or later).

There is no source code here. Each release is a signed and notarized build.
